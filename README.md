# 解忧树洞

校园语音倾诉与教师回应装置 · ESP32-S3 固件

“解忧树洞”面向校园中的倾诉与教师回应需求，由学生语音终端和教师工作台组成。学生按键录音后，语音通过校园局域网发送到教师电脑；教师试听并人工选择关怀级别，确认后发送文字或语音回应。终端通过屏幕、灯光和扬声器呈现状态与回复，帮助学生表达困扰、获得教师回应。

项目基于 [xiaozhi-esp32](https://github.com/78/xiaozhi-esp32) 完成板级适配、双向语音通信和教师优先回应逻辑。装置用于辅助沟通，不作心理诊断。项目介绍参考两位成员的《解忧树洞申报书 3.2》；申报书原件中的个人资料不随固件发布。

## 功能

- **学生按键倾诉**：按住对话键录音、松开发送，使用局域网传输学生语音。
- **教师人工回应**：接收教师选择的绿、黄、红三级文字，结合屏幕和灯效提示；支持播放教师录制的语音。
- **教师优先**：教师回应优先于本地陪伴提示与启用后的云端兜底。
- **传输完整性检查**：语音分包重组、序号检查、缺包拒收与发送节流。
- **终端反馈**：心跳报告在线状态，ACK 区分本地“已发出”和终端报告“已显示／已播放”。

局域网教师回应路径不要求云服务；启用云端兜底时会向配置的服务发送本次语音，应按使用场景决定是否启用。

## 下载与使用

[固件发布与压缩包](https://github.com/wcbsdxg/jieyou-treehole/releases) 包含固件源码包、完整分区固件包和 SHA-256 校验文件。

目标硬件为 **MAG AI 1688 Mini / ESP32-S3-WROOM-1U-N16R8**：16 MB Flash、8 MB Octal PSRAM、NV3030B 屏幕、I2S 麦克风与 NS4168 功放、WS2812 灯条。本项目不采用 4G 模块。不同板型不能直接通用。

**发布的预编译包使用占位 Wi-Fi 名称、密码、示例教师端 IP 和示例心理老师电话，用于保存构建基线。实际部署前请修改配置并重新编译。**

构建固定使用 **ESP-IDF 5.4.4**。详见 [构建与配置](docs/BUILD.md)、[发布清单与验证范围](docs/RELEASE.md)、[通信协议](docs/PROTOCOL.md)。教师工作台沿用 OpenDesign 的网页设计；本次仓库发布范围为终端固件和构建产物。

# 现有终端通信协议

本次发布保留既有字节定义，不迁移线上协议。教师端默认监听 UDP 8888，终端监听 UDP 8889。

| 方向 | 格式 |
| --- | --- |
| 学生语音上行 | `XZSD` + 序号 2 字节 + 长度 2 字节 + 标志 1 字节 + payload |
| 老师语音下行 | `XZSV` + 序号 2 字节 + 长度 2 字节 + 标志 1 字节 + payload |
| 老师文字 | 单个 UTF-8 JSON：`{"level":"green|yellow|red","text":"..."}` |
| 心跳 | `XZHB`，格式以固件源码为准 |
| 终端确认 | `XZAK`，类型与结果以固件源码为准 |

分片的序号与长度为大端；标志 bit0 表示末包。每包 payload 最多 1200 字节，下行非末包固定 1200 字节；两向发送每 4 包暂停约 20 ms。

学生上行为 16 kHz、16 bit、单声道 WAV；教师下行为 8 kHz、16 bit、单声道 WAV。下行整段（含 44 字节 WAV 头）不得超过 320000 字节，必须所有分片到齐并通过格式校验后才播放。

文字 JSON 最多 1024 字节。ACK 表示终端报告已应用或已播放，不证明学生一定听见。现协议没有消息 ID、不提供 UDP 重传；同一目标、同一类型的迟到 ACK 仍可能存在归属歧义。
